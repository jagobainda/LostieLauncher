# Report a problem or suggest an idea

You do not need programming knowledge to help improve LostieLauncher.
An issue is simply a public report on GitHub. You need a GitHub account to post one.

## Before you post

- Check that you are using the latest launcher version.
- Look through [existing reports](https://github.com/jagobainda/LostieLauncher/issues)
  to see whether someone has already reported the same thing. If so, add any
  useful details there.

## Report a problem

[Open a new issue](https://github.com/jagobainda/LostieLauncher/issues/new)
and give it a clear title, such as **Android: download stops halfway through**.

Copy this into the description and fill in what you know:

```text
Device and system: (for example, Windows 11 or Samsung Galaxy A54 / Android 14)
Launcher version: (shown in Settings)
Game: (if the problem affects a particular game)
What I did:
1.
2.
What I expected:
What happened instead:
```

If an error message appears, include its text or a screenshot. A short video
can also help. Hide any personal information or download keys before posting.
If you cannot find a detail, explain the rest in your own words.

## Suggest an idea

[Open a new issue](https://github.com/jagobainda/LostieLauncher/issues/new),
describe what you would like to do and explain how it would help. Mention
whether your idea is for Windows, Android or both.
