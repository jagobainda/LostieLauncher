# Third-party assets

The shell's icons are the same glyphs the desktop draws through
MahApps.Metro.IconPacks, converted to Android vector drawables. The path data
is unchanged; only the container format differs.

| Drawable | Source icon | Project | Licence |
| --- | --- | --- | --- |
| `ic_nav_home` | `house` | [Lucide](https://lucide.dev) | ISC |
| `ic_nav_games` | `play` | Lucide | ISC |
| `ic_nav_library` | `download` | Lucide | ISC |
| `ic_nav_refresh` | `refresh-cw` | Lucide | ISC |
| `ic_nav_faqs` | `circle-question-mark` | Lucide | ISC |
| `ic_nav_settings` | `cog` | Lucide | ISC |
| `ic_debug_tools` (debug only) | `bug` | Lucide | ISC |
| `ic_offline` | `cloud-off-outline` | [Material Design Icons](https://pictogrammers.com/library/mdi/) | Apache-2.0 |
| `ic_social_github` | `github` | [Simple Icons](https://simpleicons.org) | CC0-1.0 |
| `ic_social_twitch` | `twitch` | Simple Icons | CC0-1.0 |
| `ic_social_youtube` | `youtube` | Simple Icons | CC0-1.0 |
| `ic_social_x` | `x` | Simple Icons | CC0-1.0 |

Simple Icons are CC0, but the marks they depict remain their owners'
trademarks; they are used only to link to the corresponding profiles, as the
desktop does.

`drawable-nodpi/launcher_logo.png` is the project's own
`/public/imgs/logo-launcher.png`, the image the desktop loads from the CDN as
its window icon. It is bundled here so the title bar does not depend on the
network.
